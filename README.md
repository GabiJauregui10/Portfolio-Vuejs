# 🌐 Portfolio Personal - Gabriel Jauregui

¡Hola! 👋

Este repositorio contiene el código fuente de mi **portfolio personal**, desarrollado con **Vue.js** y **Vite**.

El objetivo de este proyecto es presentar mi perfil como desarrollador, mostrar mis conocimientos, proyectos y tecnologías de una manera moderna, organizada y responsive.

# ⚙️ Instalación

Clonar el repositorio

```bash
git clone https://github.com/GabiJauregui10/Portfolio-Vuejs.git
```

Instalar dependencias

```bash
npm install
```

Ejecutar el proyecto

```bash
npm run dev
```

Generar la versión de producción

```bash
npm run build
```
