# Proyecto Vue con Vite

Esta plantilla te ayudará a comenzar a desarrollar con **Vue** utilizando **Vite** como entorno de desarrollo rápido y moderno.

---

## 💻 Configuración del entorno recomendada

Para obtener la mejor experiencia de desarrollo, se recomienda usar:

- **[Visual Studio Code (VS Code)](https://code.visualstudio.com/)**  
- Extensión oficial de Vue: **[Vue (Official)](https://marketplace.visualstudio.com/items?itemName=Vue.volar)**  
  *(Desactiva la extensión “Vetur” si la tenés instalada, ya que puede generar conflictos con Volar.)*

---

## 🌐 Configuración del navegador recomendada

### 🔹 Navegadores basados en Chromium  
(Chrome, Edge, Brave, etc.)

- Instalar la extensión **[Vue.js devtools](https://chromewebstore.google.com/detail/vuejs-devtools/nhdogjmejiglipccpnnnanhbledajbpd)**  
- Activar la opción **“Custom Object Formatter”** en las herramientas de desarrollo de Chrome:  
  [Ver cómo activarlo](http://bit.ly/object-formatters)

### 🔹 Firefox

- Instalar la extensión **[Vue.js devtools](https://addons.mozilla.org/en-US/firefox/addon/vue-js-devtools/)**  
- Activar la opción **“Custom Object Formatter”** en las herramientas de desarrollo de Firefox:  
  [Ver cómo activarlo](https://fxdx.dev/firefox-devtools-custom-object-formatters/)

---

## 🚀 Configuración del proyecto

Instalá las dependencias necesarias con:

```bash
npm install


### Compilar y recargar en caliente para el desarrollo

```bash
npm run dev
```

### Compilar y minimizar para producción

```bash
npm run build
```

### Lint with [ESLint](https://eslint.org/)

```bash
npm run lint
```
🧩 Tecnologías utilizadas

Este proyecto fue creado con las siguientes herramientas y tecnologías:

🟩 Vue.js 3 – Framework progresivo de JavaScript para interfaces de usuario.

⚡ Vite – Herramienta de compilación rápida y moderna.

🧱 HTML5 – Estructura base del contenido.

🎨 CSS3 – Estilos visuales y diseño responsivo.

💛 JavaScript (ES6+) – Lógica y comportamiento dinámico del proyecto.

🔧 Node.js y npm – Entorno y gestor de dependencias.

🌐 Git y GitHub – Control de versiones y alojamiento del código.

🖥️ Visual Studio Code – Editor de código principal.
